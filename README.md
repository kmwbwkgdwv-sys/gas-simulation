# まんたんステーション

3Dのガソリンスタンド＆併設コンビニ経営シミュレーション。PC・スマホ（横画面専用）対応、最大5人のマルチプレイ。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | ゲーム本体 |
| `assets/cs/data.js` `gl.js` `models.js` | 人物モデル。ケーキ屋さんシミュレーターのものをそのまま読み込み、このゲームの描画に変換して使っています（お客さん・アルバイト・プレイヤー） |
| `assets/models.js` | 小物の3Dモデル（バット、バケツと雑巾、バット立て、カラーコーン、パレット、落とし物） |
| `assets/tex/*.jpg` `*.png` | テクスチャ素材（アスファルト、道路、コンクリート、床タイル、クリーム色の壁、腰壁タイル、木の床、濃い木、ダンボール、芝、金属）。`_c` が色、`_n` が凹凸（法線） |
| `firebase-config.js` | Firebase の設定を貼る場所 |
| `database.rules.json` | Realtime Database のセキュリティルール |

## 公開手順（GitHub Pages）

1. GitHub で新しいリポジトリを作り、このフォルダの中身を **`assets` フォルダごと** すべてアップロードする
2. リポジトリの Settings → Pages → Branch を `main` / `(root)` にして Save
3. 数分後に表示される URL を開く

Firebase を設定しなくてもシングルプレイは遊べます（データはその端末に保存）。

`assets/cs` が読み込めない場合、人物は簡易モデルになります。`assets` が読み込めない場合（アップロード漏れや、ファイルを直接ダブルクリックで開いた場合）は、簡易モデルと内蔵テクスチャで表示されます。

## Firebase の設定（引き継ぎ・マルチプレイ・チャットに必要）

1. Firebase コンソールでプロジェクトを開き、「Realtime Database」を作成する
2. Realtime Database の「ルール」タブを開き、`database.rules.json` の中身をすべて貼り付けて「公開」を押す
3. プロジェクトの設定 → マイアプリ（ウェブ）→「構成」の内容を `firebase-config.js` に貼り付ける
   - `databaseURL` が必ず入っていること（無い場合は Realtime Database 作成後に構成を取り直す）
4. `firebase-config.js` を GitHub にアップロードし直す

ルールは以前のままで動きます（変更不要）。

## 画面と操作

- スマホは横画面専用です。縦に持つと「横向きにしてください」と表示され、プレイは止まります
- ノッチ／ダイナミックアイランドを避けるため、UI は画面端から内側に寄せています
- 移動：左スティック / WASD　視点：画面ドラッグ　操作：対象をタップ、またはアクションボタン（PC は E キー）
- サブボタン（PC は Q キー）：持っているダンボールを開ける／閉じる
- 設定の「視点の感度」スライダーで、画面ドラッグの視点移動の速さを30%〜300%に変えられます（端末に保存）
- 設定（タイトル、またはプレイ中の右上「設定」）→「操作ボタンの位置とサイズ」で、スティック・アクションボタン・サブボタンをドラッグで移動、スライダーで大きさ変更。端末に保存されます

## 1日の流れ

1. 朝（準備中）：燃料・値段・スタッフを確認し、必要なら仕入れる
2. 店の前の立て看板をタップして **OPEN** にすると営業開始（最初は CLOSE。画面左上にも OPEN / CLOSE が出ます）
3. 営業：給油 → 窓拭き → 客が駐車場へ → 店内レジで会計。コンビニ客も来る
4. 20:00 に閉店。残っている客の対応が終わると日報が出る（看板を2回タップで早じまいも可）
5. 日報を見て「次の日へ」

朝はやわらかい光、昼は明るく、夕方から暗くなり、夜は街灯・看板・街の窓が灯ります。1日は現実の約6分です。

## お店の間取り

- 売り場（入口から入った店内）：左側に陳列棚、右手前にレジ（緑のライン＝レジ待ちの列）、右奥に管理PC、入口のすぐ右にバット立て
- 在庫スペース（店の奥の部屋）：床の青いラインをたどって左奥のドアへ。在庫棚とゴミ箱があります
- 搬入口：在庫スペースの外側のドア。配送トラックはこの外に止まります
- 主な場所には「レジ」「給油機」「雑巾」「バット」などの札が浮かんでいます

## 仕入れ・在庫

- 燃料：管理PC「燃料の発注」で注文すると、その場でタンクが満タンになります
- 商品：管理PC「商品の仕入れ」で注文 → 配送トラックが搬入口の外に到着 → 荷台のダンボールを運ぶ
- ダンボール
  - サブボタン（または持っている箱をタップ）で「開ける／閉じる」
  - 開けていても閉じていても床に置けます
  - 空にした箱は消えません。開けた空箱を持って、商品のある段に視点を合わせると「商品を箱にしまう」で再利用できます
  - いらない箱は在庫スペースの「ゴミ箱」でのみ捨てられます（中身入りは2回押しで確認）
- 在庫棚：在庫スペースに最初から1台。1台にダンボール4箱まで。管理PC「設備」で最大4台まで増やせます
- ダンボールは注文中のものも含めて合計20箱まで

## 陳列棚と値札

- 陳列棚は1台5段、1段に同じ商品を6個まで置けます
- 開けた箱を持って段に視点を合わせ（オレンジの枠が出ます）「この段に並べる」
- 並べただけでは売れません。箱を置いて、その段に視点を合わせ「値札を貼る」と売り出されます
- 値札の付いた段には、その商品しか置けません
- 段が空のときに視点を合わせて「値札を取る」と、その段にはアルバイトも何も置かなくなります
- 値札には商品名と現在の売値が表示されます

## 強盗とバット

- 強盗はふつうのお客さんと同じように来店し、商品を取ると走って逃げます。逃げている間は頭の上に「！」が出ます
- 入口のすぐ内側のバット立て（3本あります）でバットを取り、近づいて「バットで殴る！」（タップでも可）
- 1回殴ると強盗は転び、取った商品を地面に落とします。転んだ強盗はそのまま逃げていきます
- 落ちた商品（黄色い輪が目印）をタップすると回収でき、元の段に戻ります
- 店から少し離れられると逃げ切られ、商品は戻りません（日報に「盗まれた商品」として出ます）
- 強盗は、これまでの接客が4組を超えたころから現れます

## アルバイト

管理PC「スタッフ」で雇い、雇ったあとに仕事を割り当てます（最大4人、日給は閉店時に支払い）。

| ランク | 解放 | 作業の速さ | 日給 |
|---|---|---|---|
| 新人 | Lv.1 | 45% | ¥3,000 |
| 見習い | Lv.2 | 65% | ¥4,500 |
| 一人前 | Lv.3 | 85% | ¥6,000 |
| ベテラン | Lv.5 | 110% | ¥8,000 |
| 達人 | Lv.6 | 140% | ¥11,000 |

| 仕事 | 内容 |
|---|---|
| レジ | レジの会計 |
| ガソリン | 給油と窓拭き |
| 品出し | トラックから箱を運び、値札の付いた段に並べる。余りは在庫棚へ、在庫棚がいっぱいならその場の床に置く。空になった箱はゴミ箱へ捨てる |
| 強盗退治 | 入口で待機し、逃げる強盗を止めて落とした商品を戻す（ランクが低いと間に合わないことが多い） |

お客さんの見た目は毎回ランダム、給油に来る車も7車種×12色からランダムです。

## はじめの状態

- 新しく始めたお店は、陳列棚1台・ガソリン専用棚1台だけで、商品は何もありません
- 管理PCで仕入れ → 搬入口のトラックから箱を運ぶ → 箱を開けて棚に並べる → 値札を貼る、で売り出せます

## 商品の大きさと棚

- ダンボール1箱は8個入り。携行缶・エンジンオイル・ウォッシャー液は4個入り
- ふつうの棚：小さい商品は1段8個、カップ麺と弁当は1段6個
- 携行缶・エンジンオイル・ウォッシャー液は大きいので、ガソリン専用棚（3段・1段4個）にしか置けません。逆に、専用棚に小さい商品は置けません
- ガソリン専用棚は最初から1台。Lv.3 で管理PC「設備」からもう1台（¥12,000）買えます
- 商品は種類ごとに形が違います（おにぎり、ペットボトル、缶、カップ麺、弁当、サンド、携行缶など）

## 配置（棚とレジを動かす）

- CLOSE のあいだ、画面右上の「配置」を押すと配置モードになります
- 動かしたい棚かレジに視点を合わせて「動かす」→ 床に視点を向けて場所を決める →「ここに置く」。サブボタンで向きを変えられます
- 緑の枠は置ける場所、赤は置けない場所（壁・入口や裏口の前・事務机・ほかの家具に近すぎる所）
- 棚の中の商品と値札はそのまま一緒に動きます

## レジ

1. お客さんがレジに来たら、近づいて「レジに立つ」
2. カウンターの商品に視点を合わせて、1つずつ「スキャンする」（給油のお客さんは給油伝票）
3. お客さんが差し出した現金かカードに視点を合わせて受け取る
4. 現金：下のレジ（ドロア）が開くので、お札・硬貨に視点を合わせて取り、お客さん側のトレーに視点を合わせて「お釣りを渡す」。足りないと渡せません。多く渡すとその分は損になります。選び直しはサブボタン
5. カード：カード端末のキーに視点を合わせて合計金額を入力し「OK」。違うとやり直しです

モニターに、スキャン済みの商品・合計・お預かり・お釣りが表示されます。画面を直接タップしても同じ操作ができます。

## 給油

- 車か給油機をタップ → ノズル（油種）を選ぶ → 速く動くゲージを **緑のところでタップして止める**
- 5回成功すると満タン（1回成功ごとに注文量の1/5ずつ入ります）
- 外すたびにガソリンを1.5Lむだにします
- タンクの残量は、この給油画面と管理PC「燃料の発注」で確認できます（店内の壁のメーターは無くしました）

## 値段

- 商品は、棚の値札に視点を合わせて「◯◯の値段を変える」。燃料（レギュラーなど）と全商品は管理PC「価格」でも変えられます
- 何もしなければ相場の1.2倍で売ります。1.2倍までは普通に売れます
- 1.4倍にすると買ってくれるお客さんは6割ほど、1.7倍でまったく売れなくなります
- レギュラーを安くすると、来る車が少し増えます

## マルチプレイとチャット

- 「マルチプレイ」→「ルームを作る」で5文字のコードを発行。仲間は同じコードで参加（最大5人）
- お店はルームを作った人（ホスト）のもの。売上・レベルはホストのデータに入ります
- ルームにいる間は右上の「チャット」からテキストを送れます。届いたメッセージは画面の左から通知として流れてきます
- ホストがゲーム画面を閉じたり別アプリに切り替えたりすると、お店の時間が止まります

## 画質モード

設定で切り替えられます（切り替えると読み込み直します）。メモリの少ない端末以外は、最初から「きれい」になります。

| モード | 内容 |
|---|---|
| きれい | 影、空や周囲の映り込み、金属・ガラスの質感、路面や床のテクスチャ、雲と遠くの山並み、高解像度表示 |
| 軽量 | 影・映り込み・細かい小物を省略、30fps |

どちらのモードでも、スタンドの周りにビル街・商店・住宅・街路樹・街灯・信号のある街並みが表示され、夜は窓明かりと星が出ます。
