# まんたんステーション

3Dのガソリンスタンド＆併設コンビニ経営シミュレーション。PC・スマホ（横画面）対応、最大5人の協力プレイ。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | ゲーム本体（これ1つで動きます） |
| `firebase-config.js` | Firebase の設定を貼る場所 |
| `database.rules.json` | Realtime Database のセキュリティルール |

## 公開手順（GitHub Pages）

1. GitHub で新しいリポジトリを作り、このフォルダの中身をすべてアップロードする
2. リポジトリの Settings → Pages → Branch を `main` / `(root)` にして Save
3. 数分後に表示される URL を開く

Firebase を設定しなくても1人プレイは遊べます（データはその端末に保存）。

## Firebase の設定（引き継ぎ・ルーム・チャットに必要）

1. Firebase コンソールでプロジェクトを開き、「Realtime Database」を作成する
2. Realtime Database の「ルール」タブを開き、`database.rules.json` の中身をすべて貼り付けて「公開」を押す
3. プロジェクトの設定 → マイアプリ（ウェブ）→「構成」の内容を `firebase-config.js` に貼り付ける
   - `databaseURL` が必ず入っていること（無い場合は Realtime Database 作成後に構成を取り直す）
4. `firebase-config.js` を GitHub にアップロードし直す

### ルールの内容

- 読み書きできるのは `mantan/` 以下だけ。それ以外はすべて拒否
- `mantan/saves/GS-XXXX-XXXX`：引き継ぎコードと同じ名前の場所にだけセーブデータ（4,000文字未満の文字列）を保存。一覧は取得できないので、コードを知らない人はデータを読めません
- `mantan/rooms/XXXXX`：ルームごとにプレイヤー位置・お店の状態・チャット／操作メッセージを置く。大きさと形式を制限
- ログイン機能は使っていないため、引き継ぎコードを知っている人はそのデータを上書きできます。コードは人に見せないでください

## 遊び方

- 移動：左スティック / WASD　視点：画面ドラッグ　操作：対象をタップ（クリック）、または画面下のボタン（PCは E キー）
- 給油：車か給油機をタップ → ノズル（油種）を選ぶ → ボタンを長押し。希望量以上で完了
- 窓拭き：給油機横のバケツで雑巾を取る → 車の窓をタップ → 画面をこすって汚れを落とす
- 会計：給油と窓拭きが終わると客が駐車場に車を移し、店内レジに並ぶ。現金はお金を受け取ってからお釣りを選んで渡す。カードはスキャンするだけ
- 管理PC（店内の右奥）：燃料の発注、商品の仕入れ、陳列棚の購入と配置
- 燃料の残量は店内奥の壁のメーターで確認できます

## 画質モード

タイトル画面とメニューで切り替えられます（切り替えると読み込み直します）。

| モード | 内容 |
|---|---|
| きれい | 影、空や周囲の映り込み、金属・ガラスの質感、路面や床のテクスチャ、雲、街路樹・街灯・遠景のビル、店内と屋根下の照明 |
| 軽量 | 影・映り込み・テクスチャ・背景物をすべて省略、解像度を下げ、30fps に制限 |

メモリやCPUの少ないスマホでは、初回だけ自動で軽量モードになります。

## 協力プレイ

- 「ルーム」→「ルームを作る」で5文字のコードを発行。仲間は同じコードで参加（最大5人）
- お店はルームを作った人（ホスト）のもの。売上・レベルはホストのデータに入ります
- ホストがゲーム画面を閉じたり別アプリに切り替えたりすると、お店の時間が止まります
