# まんたんステーション（v8）

3Dのガソリンスタンド＆併設コンビニ経営シミュレーション。PC・スマホ（横画面専用）対応、最大5人のマルチプレイ。

## 公開手順（GitHub Pages）

1. このフォルダの中身を **`assets` フォルダごと** すべてリポジトリにアップロードする（以前のファイルは上書き）
2. Settings → Pages → Branch を `main` / `(root)` にして Save

## Firebase（引き継ぎ・マルチプレイ・チャット・ランキング）

- `firebase-config.js` に構成を貼る（以前のままで OK）
- **v8 ではルールが変わりました。** Realtime Database の「ルール」に `database.rules.json` の中身を貼り直して「公開」してください（ランキング用の `rank` を追加、セーブとルームの上限を拡大）

## 操作

| | スマホ | パソコン |
|---|---|---|
| 移動 | 左スティック | WASD（設定で変更可） |
| 視点 | 画面ドラッグ | 画面をクリック → マウスを動かすだけ（Esc で解除）。ドラッグでも可 |
| アクション | アクションボタン／画面中央をタップ | E または左クリック |
| サブ・サブ2 | サブボタン | Q・F（右クリック＝サブ） |

- アクションは **画面中央の丸（視点）を合わせた物** で決まります
- 設定 →「キー配置」でキーを変えられます。ボタンの位置と大きさも変えられます

## 1日の流れ

1. CLOSE のあいだに仕入れ・値付け・配置
2. 店の前の看板に視点を合わせて **OPEN**
3. 営業（給油・窓拭き・レジ・掃除・品出し）。20:00 を過ぎると新しいお客さんは来ません
4. 看板に視点を合わせて「次の日へ進む」→ 確認（いるお客さんと会計前の商品は消えます）→ 日報 → 次の日

日報：売上（燃料・コンビニ・自販機・窓拭き）、支出、利益、来たお客さん、不快にさせた数、待ちきれずに帰った客、盗まれた商品の総額。

## お店

- 売り場は幅14m×奥行10m（以前の約半分）。奥が在庫スペース、その先が搬入口
- 管理PCは店内の右奥。水道は店の左の外壁
- 棚・レジ・在庫棚の当たり判定は小さくなりました

## 給油

1. 給油機のノズル（赤＝レギュラー／黄＝ハイオク／緑＝軽油）に視点を合わせて「ノズルを持つ」
2. ノズルを持ったまま、車の **給油口（緑の枠）** に視点を合わせて「給油する」
3. 縦のゲージ（目盛りは注文量の2倍まで）を **1回で止める**
   - 緑の線（注文量）より上＝成功。入れすぎても代金は注文分だけ
   - 緑の線より下＝ミス。代金は入れた分だけで、不快数が増えます
- 車種ごとに油種が決まっています（スポーツカーはハイオク、SUV・ミニバン・軽トラは軽油など）
- 給油を90秒待たされたお客さんは帰ります（ときどき愚痴が出ます）
- パトカー・スーパーカー・高級スポーツカーはめずらしい車です。窓は透明で、運転している人が見えます

## 窓拭き・掃除

- 窓拭きが必要な車は約40%。拭くと窓拭き代 ¥300 が会計に加わります
- 道具（バット・雑巾・バケツ・モップ）は最初に1つずつ。どこにでも置けて、管理PC「お店・道具」でいつでも買えます
- バケツを持って水道へ →「水を入れる」（約5秒）→ 水バケツを好きな床に置く
- 雑巾／モップを持って、床の水バケツに視点を合わせて「濡らす」。水は3回で使えなくなるので、水道で入れ替えます
- 雑巾は濡れていないと窓を拭けません（1回濡らすと約3台分）
- 床の汚れ（お客さんがたまに落とす）は、濡らしたモップを持って視点を合わせ、**視点を動かしてこする** と落ちます
- 汚れがたまると、お客さんの来るペースが下がります

## レジ

1. レジの **内側（お客さんが並ぶ反対側）** で「レジに立つ」。立てるのは1人だけ
2. 商品に視点を合わせて1つずつスキャン → 現金／カードを受け取る
3. カードは自分の画面にだけテンキーが出るので合計を入力。現金は自分の画面のレジからお釣りを選んで渡す

## 仕入れ・棚

- 管理PC「仕入れ（カート）」で商品をカートに入れて「発送する」。1回10箱まで、送料は何箱でも ¥1,000
- 箱を開けて段に視点を合わせ「1つ並べる」／「まとめて並べる」
- 値札は、値札そのものに視点を合わせても値段を変えられます
- 陳列棚（最大12台）・ガソリン専用棚（最大4台）もカートで注文。ダンボールで届くので、持って置きたい床に視点を合わせて「ここに棚を置く」
- 棚の箱は在庫棚に横2枠で収納できます。CLOSE 中の「配置」で棚を選ぶと「ダンボールに梱包する」もできます
- 燃料は「燃料の発注」でゲージを動かして量を選びます

## 値段

- 何もしなければ相場の1.1倍。高くするほど買う人が減ります（1.2倍で約8割、1.7倍で売れません）
- 自販機：飲み物の箱を開けて持ち、自販機に視点を合わせて補充。値段は店売りの約1.1倍が初期値で、自販機か管理PC「価格」で変えられます

## お客さんと強盗

- お客さんは、買いたい商品の棚まで歩いて取りに行きます
- おじさん、ちょっと変な人、はだかの人、宇宙人など、いろいろな人が来ます
- 強盗は商品を取って走って逃げます。**店を出ると赤く光り**、通知が出ます
- バットを持つと「バットを振る」がいつでも使えます（ふつうのお客さんを殴ると怒って帰ります）
